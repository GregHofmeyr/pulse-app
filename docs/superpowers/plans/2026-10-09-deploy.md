# Pulse Deployment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pulse running on the internet at `https://pulsechat.co.za` (voice at `voice.pulsechat.co.za`), hardened, backed up and monitored, ready for the Windows test with friends.

**Architecture:** Code changes first (rate limits, 24 h invites, version handshake, `backup` subcommand, pre-filled server URL), each test-driven on the laptop. Then the deployable pieces: a server image built by GitHub Actions for amd64 + arm64, a `deploy/` folder (Compose stack of Caddy + pulse-server + LiveKit, an idempotent `setup.sh`, backup/restore scripts, runbook), and `just` recipes to provision, deploy, back up and restore over Tailscale. Last, the live rollout on the Oracle box, with Greg doing the console/account steps.

**Tech Stack:** Rust (axum 0.8, sqlx/SQLite), Tauri 2 + Svelte 5 client, Docker Compose, Caddy 2.10, LiveKit 1.13.7, Tailscale, age, rclone → Cloudflare R2, GitHub Actions + GHCR, UptimeRobot.

**Spec:** `docs/superpowers/specs/2026-10-09-deploy-design.md`

## Global Constraints

- Public names: `pulsechat.co.za` (Pulse server) and `voice.pulsechat.co.za` (LiveKit signalling). Cloudflare DNS **proxy off**.
- The repo is **public**: never commit the server's IP address, secrets, Greg's email, or friends' names. Scripts take them as arguments or read them from `/srv/pulse/.env` on the server.
- Image: `ghcr.io/greghofmeyr/pulse-server` (lowercase), tags `:<7-char sha>` and `:latest`, platforms `linux/amd64` + `linux/arm64`.
- Pinned images: `livekit/livekit-server:v1.13.7` (same as the Windows kit's `LIVEKIT_VERSION`), `caddy:2.10`.
- Containers run as the host `pulse` user (`PULSE_UID`/`PULSE_GID` in `.env`), never root.
- Docker logs rotate: `json-file`, `max-size 10m`, `max-file 3`.
- Firewall inbound allow-list: `80/tcp 443/tcp 7881/tcp 7882/udp 3478/udp 41641/udp` (41641 = Tailscale direct connections). No public SSH once Tailscale SSH works.
- Rate limits (spec §3.1): login 5/min per IP + 10/hour per username; register 5/hour per IP; send burst 20 refill 5/s per user; typing 1/s per user. 429 code `rate_limited`.
- Invites valid 24 h. Expired = same 404 as unknown.
- Protocol version handshake: `PROTOCOL_VERSION = 1`, `MIN_CLIENT_VERSION = 1`, close code **4005**, UI text **"plz update :)"**.
- Release builds pre-fill `https://pulsechat.co.za`; dev keeps `http://127.0.0.1:7890`.
- `just check` stays green after every code task. Every server/client change follows TDD (watch it fail first).
- Live-server steps (Tasks 14–18) touch real accounts and the real box: each one is announced, and Greg does the console/account clicks.

## Review Focus

1. **Friends on one network log in or register together** (LAN, same house): only *failed* logins / bad invite codes spend rate-limit tokens, so 8 good logins from one IP all succeed → pinned in Task 2 (`failed_logins_are_limited_per_ip_but_good_ones_are_not`, `bad_invite_codes_are_limited_per_ip_but_registrations_are_not`).
2. **A client forging `X-Forwarded-For`** to dodge limits: only the right-most entry (the one Caddy writes) counts → pinned in Task 1 (`client_ip_takes_the_entry_caddy_appended`).
3. **Mixed versions during an update:** an old client (no `client_version`) sees "plz update :)" instead of a reconnect loop; a new client against a not-yet-updated server still connects (unknown fields are ignored) → pinned in Tasks 5–6 (`outdated_client_is_told_to_update`, `hello_ignores_unknown_fields`, `update_required_stops_reconnecting`).
4. **A backup that fails half-way** must not leave a plaintext copy of the database on the server → `trap` in `backup.sh` (Task 12) plus the explicit check in Task 17 step 4.
5. **Invite right at the edge of 24 h**: 23 h old works, 25 h old is a 404 indistinguishable from a typo → pinned in Task 4 (`invites_expire_after_24_hours`).

```rust
//! Rate limits: in-memory token buckets (one node, so no shared store is needed).

use std::collections::HashMap;
use std::net::{IpAddr, Ipv4Addr, SocketAddr};
use std::sync::Mutex;
use std::time::Instant;

use axum::extract::{ConnectInfo, FromRequestParts};
use axum::http::request::Parts;

/// A bucket of `burst` tokens, topped up at `refill_per_sec`.
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct Rate {
    pub burst: u32,
    pub refill_per_sec: f64,
}

impl Rate {
    pub const fn new(burst: u32, refill_per_sec: f64) -> Self {
        Self { burst, refill_per_sec }
    }
    pub fn per_minute(n: u32) -> Self {
        Self::new(n, n as f64 / 60.0)
    }
    pub fn per_hour(n: u32) -> Self {
        Self::new(n, n as f64 / 3600.0)
    }
}

#[derive(Clone, Copy, Debug)]
pub struct LimitsConfig {
    /// Failed logins per client IP.
    pub login_ip: Rate,
    /// Failed logins per username.
    pub login_user: Rate,
    /// Failed registrations (unknown/used/expired invite) per client IP.
    pub register_ip: Rate,
    /// Messages sent per user.
    pub send_user: Rate,
    /// Typing frames per user (extra ones are dropped).
    pub typing_user: Rate,
}

impl Default for LimitsConfig {
    fn default() -> Self {
        Self {
            login_ip: Rate::per_minute(5),
            login_user: Rate::per_hour(10),
            register_ip: Rate::per_hour(5),
            send_user: Rate::new(20, 5.0),
            typing_user: Rate::new(1, 1.0),
        }
    }
}

impl LimitsConfig {

/// Extractor for [`client_ip`]. Never rejects.
pub struct ClientIp(pub IpAddr);

impl<S: Send + Sync> FromRequestParts<S> for ClientIp {
    type Rejection = std::convert::Infallible;

    async fn from_request_parts(parts: &mut Parts, _: &S) -> Result<Self, Self::Rejection> {
        let xff = parts.headers.get("x-forwarded-for").and_then(|v| v.to_str().ok());
        let peer = parts.extensions.get::<ConnectInfo<SocketAddr>>().map(|c| c.0.ip());
        Ok(Self(client_ip(xff, peer)))
    }
}

    }

    #[test]
    fn idle_buckets_are_swept_when_the_map_is_full() {
        let l = Limiter::new(Rate::new(2, 1.0));
        let t0 = Instant::now();
        for i in 0..MAX_KEYS {
            l.hit_at(&format!("k{i}"), t0);
        }
        assert_eq!(l.len(), MAX_KEYS);
        // 10 s later every bucket is full again: a new key sweeps them out.
        l.hit_at("new", t0 + Duration::from_secs(10));
        assert_eq!(l.len(), 1);
    }

    #[test]
    fn client_ip_takes_the_entry_caddy_appended() {
        let ip = |s: &str| s.parse::<IpAddr>().unwrap();
        let peer = Some(ip("127.0.0.1"));
        assert_eq!(client_ip(Some("203.0.113.7"), peer), ip("203.0.113.7"));
        // a client can't dodge limits with its own header: the proxy's entry is last
        assert_eq!(client_ip(Some("1.2.3.4, 203.0.113.7"), peer), ip("203.0.113.7"));
        assert_eq!(client_ip(Some(" 2001:db8::1 "), peer), ip("2001:db8::1"));
        assert_eq!(client_ip(Some("garbage"), peer), ip("127.0.0.1"));
        assert_eq!(client_ip(None, peer), ip("127.0.0.1"));
        assert_eq!(client_ip(None, None), ip("0.0.0.0"));
    }
```

```rust
    pub fn allowed_at(&self, key: &str, now: Instant) -> bool {
        self.with(key, now, |t| *t >= 1.0)
    }

    pub fn hit_at(&self, key: &str, now: Instant) -> bool {
        self.with(key, now, |t| {
            if *t >= 1.0 {
                *t -= 1.0;
                true
            } else {
                false
            }
        })
    }

    fn with(&self, key: &str, now: Instant, f: impl FnOnce(&mut f64) -> bool) -> bool {
        let rate = self.rate;
        let mut map = self.buckets.lock().unwrap();
        if map.len() >= MAX_KEYS && !map.contains_key(key) {
            map.retain(|_, b| refilled(b, now, rate) < rate.burst as f64);
        }
        let b = map
            .entry(key.to_owned())
            .or_insert(Bucket { tokens: rate.burst as f64, at: now });
        b.tokens = refilled(b, now, rate);
        b.at = now;
        f(&mut b.tokens)
    }
```

```rust
fn refilled(b: &Bucket, now: Instant, rate: Rate) -> f64 {
    let secs = now.saturating_duration_since(b.at).as_secs_f64();
    (b.tokens + secs * rate.refill_per_sec).min(rate.burst as f64)
}
```

```bash
#!/usr/bin/env bash
# Encrypted database backups to Cloudflare R2 (deploy/README.md, "Backups"). Runs as `pulse`.
#   backup.sh [run]      snapshot → age-encrypt → upload → prune   (pulse-backup.service, just deploy)
#   backup.sh latest     print the newest daily backup's object name
#   backup.sh fetch OBJ  write backup OBJ (still encrypted) to stdout
set -euo pipefail
cd /srv/pulse
set -a
# shellcheck source=/dev/null
. ./.env
set +a
export RCLONE_CONFIG_R2_TYPE=s3 RCLONE_CONFIG_R2_PROVIDER=Cloudflare RCLONE_CONFIG_R2_NO_CHECK_BUCKET=true \
  RCLONE_CONFIG_R2_ACCESS_KEY_ID="${R2_ACCESS_KEY_ID:-}" RCLONE_CONFIG_R2_SECRET_ACCESS_KEY="${R2_SECRET_ACCESS_KEY:-}" \
  RCLONE_CONFIG_R2_ENDPOINT="https://${R2_ACCOUNT_ID:-unset}.r2.cloudflarestorage.com"
remote="r2:${R2_BUCKET:-unset}"

case "${1:-run}" in
  latest) rclone lsf "$remote/daily" | sort | tail -n1 | sed 's|^|daily/|'; exit 0 ;;
  fetch) rclone cat "$remote/${2:?object name}"; exit 0 ;;
  run) ;;
  *) echo "usage: backup.sh [run|latest|fetch OBJ]" >&2; exit 2 ;;
esac

if [[ -z ${AGE_RECIPIENT:-} || -z ${R2_BUCKET:-} ]]; then
  echo "backups not configured yet (AGE_RECIPIENT / R2_* empty in .env): skipping" >&2
  exit 0
fi
if ! docker compose ps --status running --services | grep -qx pulse-server; then
  echo "pulse-server isn't running: nothing to back up" >&2
  exit 0
fi

ts=$(date -u +%Y%m%dT%H%M%SZ)
snap="data/backup-$ts.db"
# The plaintext snapshot must never outlive this script, whatever happens.
trap 'rm -f "$snap" "$snap.age"' EXIT
docker compose exec -T pulse-server pulse-app-server backup "/data/backup-$ts.db"
age -r "$AGE_RECIPIENT" -o "$snap.age" "$snap"
rm -f "$snap"
rclone copyto "$snap.age" "$remote/daily/pulse-$ts.db.age"
if [[ $(date -u +%u) == 7 ]]; then rclone copyto "$snap.age" "$remote/weekly/pulse-$ts.db.age"; fi
rclone delete "$remote/daily" --min-age 14d
rclone delete "$remote/weekly" --min-age 56d
echo "backed up pulse-$ts.db.age"
```
