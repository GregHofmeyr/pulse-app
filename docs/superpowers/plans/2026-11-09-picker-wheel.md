# Picker wheel (#158)

Design: `docs/superpowers/specs/2026-11-09-picker-wheel-design.md`. One person spins, everyone in the chat watches the
same spin land; the server draws the winner and the final angle. Saved wheels are Server (anyone in the server) or Just
me (the owner only). TDD throughout: each task starts with its failing tests.

## Builder's calls (with why)

- **The spin is a system line with a payload**, like call lines (#50) and Quote of the Year cards: `messages.kind =
  'system'`, `system_payload = {"type":"wheel_spin", …}`, read back into `Message.wheel: Option<WheelSpin>`. History,
  search, previews and unreads then treat it like every other system line, and the existing `MessageCreated` is the
  realtime event that carries the spin to the channel (no new spin event). Old clients show the stored text.
- **Stored text** `🎡 alex spun Games tonight → Valheim` ("a quick wheel" for one-offs): what previews, search and old
  clients read. The new client renders the line from the payload (live display name, swatch, buttons).
- **A `wheel_spins` table** keyed by the line's message id keeps each spin's options, winner and angle, so **Spin
  again** / **Remove winner & spin** run on the server from the stored spin (`POST /messages/{id}/spin-again`): a
  chain can't be spoofed and needs nothing from the client but the choice.
- **Angle**: degrees in [0, 360), the wheel's final clockwise rotation. Slice `i` of `n` covers [i·s, (i+1)·s) clockwise
  from 12 o'clock (s = 360/n); the pointer at the top then reads slice `floor(((360 − angle) mod 360) / s)`. The server
  draws the winner (rand's thread RNG, a CSPRNG) and a point 10–90 % across its slice, so it never lands on an edge.
  Every client animates 5 whole turns plus the angle over the same fixed duration, so all of them show the same spin.
- **Live or settled**: a client animates a spin only when the line mounts within 1 s of the spin reaching it (the
  `MessageCreated` event or the spinner's own response). Opening the chat later, or mid-spin, mounts it settled.
- **Quiet spins**: reduced motion, being live (streaming) or an unfocused window → a 0.4 s spin and no tick (the
  existing `shouldAnimate` inputs). Otherwise 4.5 s, ease-out quartic, a tick per slice under the pointer (throttled to
  one per 80 ms: the core opens an output stream per sound).
- **The tick** is a new UI sound `wheel_tick` in every sound set (generated by `scripts/gen_sounds.py`), played by the
  core like the others, so it follows the sound set, the output device and the volume mixer (Notifications ›
  Picker wheel tick; 0 % = off).
- **Saved wheels are fetched when a popover or Settings page opens** (not in Ready: up to 50 wheels × 100 options per
  server would bloat every connect). `WheelSaved` / `WheelDeleted` events keep an open list live (server wheels to
  everyone, as servers are public; Just me wheels to the owner only).
- **Limits**: 2–100 options, 1–60 characters each (trimmed, no blanks; duplicates allowed, the editor skips them),
  names 1–40 characters, 50 wheels per server and 50 Just me wheels per person (checked inside the insert's
  transaction), spins one per 3 s per person (`wheel_spin_user`), saved-wheel writes 30 at once then 1/s
  (`wheel_user`).
- **Where**: text channels, voice channels' chats, DMs and groups. Quotes and clips channels refuse (400). Server
  wheels spin only in their own server's channels; Just me wheels anywhere you can post.
- **SVG, not canvas**, for the shared `Wheel` component: the gaps and rim take theme tokens from CSS, labels are DOM
  text (tests can read them), and 100 slices is 200 elements. Labels are cut to fit by a character estimate.
- **Colours**: `lib/wheelColours.ts` is the one place slice colours are made (`hsl(360·i/n 100% 58%)`) and the label
  colour picked per slice (white where it reaches 3:1 on the slice, as bold labels do, else near-black); `.svelte`
  files never write the literals, and `colorTokens.test.ts` gains a check that names the helper as the one exception.

## Server and protocol

1. **Protocol** (`rest.rs`, export in `lib.rs`): `WheelScope { Server, Personal }`; `Wheel { id, scope, server_id?,
   owner_id?, name, options, updated_at }`; `CreateWheelRequest { server_id?, name, options }` (no server = Just me);
   `UpdateWheelRequest { name?, options? }`; `SpinWheelRequest { wheel_id?, options? }` (exactly one);
   `SpinAgainRequest { remove_winner }`; `WheelSpin { spinner_id?, wheel_id?, name?, options, winner, angle }`;
   `Message.wheel` (optional, skipped when absent). Gateway: `WheelSaved { wheel }`, `WheelDeleted { wheel_id,
   server_id?, owner_id? }`; `only_for` = the owner for Just me wheels. Limit constants in `rest::wheel_limits`.
2. **Migration `0029_wheels.sql`** (0028 is pins, #178): new tables only. `wheels` (id, server_id → servers CASCADE,
   owner_id → users CASCADE, exactly one of the two by CHECK, name, options JSON, created_by → users SET NULL,
   created_at, updated_at) with an index per scope; `wheel_spins` (message_id PK → messages CASCADE, channel_id →
   channels CASCADE, spinner_id → users SET NULL, wheel_id → wheels SET NULL, name, options JSON, winner, angle,
   created_at). No rebuilds; rollback = drop both.
3. **Saved wheels** (`server/src/wheels/{mod,routes}.rs`): `GET /servers/{id}/wheels` (members), `GET /wheels/mine`,
   `POST /wheels`, `PATCH /wheels/{id}`, `DELETE /wheels/{id}`. A server wheel needs membership of its server (403);
   someone else's Just me wheel is 404. Caps in the write transaction. Publish `WheelSaved` / `WheelDeleted`.
4. **Spins**: `POST /channels/{id}/wheel-spins` and `POST /messages/{id}/spin-again`. Channel access as sending a
   message (`channel_for`, server membership for server channels, quotes/clips refused). Rate limit first. Insert the
   system line and the `wheel_spins` row in one transaction, then publish `MessageCreated`; return the `Message`.
   `system::insert` parses `wheel` from the payload as it does `call`, and history loading too.
5. **Tests** (`server/tests/wheels.rs`): CRUD and permissions for both scopes; caps; validation; spin from options
   and from a saved wheel (server wheel in another server refused, someone's Just me wheel 404, DMs only for
   members, quotes refused); the winner/angle invariant over many spins; two sockets receive the identical spin;
   spin-again and remove-winner (and refusing a last option); the rate limit; deleting a channel (purge) and a group's
   last member leaving remove its spins; history returns `wheel`.

## Client

6. **Core** (`api.rs`, `commands.rs`, `lib.rs`): `list_server_wheels`, `list_my_wheels`, `create_wheel`,
   `update_wheel`, `delete_wheel`, `spin_wheel`, `spin_again`; `tauri.ts` wrappers. The tick sound: `wheel_tick` in
   `sounds.rs` NAMES, wavs from `gen_sounds.py` for every set, `voiceui.ts` names/labels, a mixer notch.
7. **Pure helpers** (`lib/wheel.ts`, `lib/wheelColours.ts`): `/wheel` parsing, `splitOptions`, `addOptions`
   (dedupe, caps), shuffle, `winnerAt(angle, n)`, the spin's rotation at time t, the slice under the pointer, label
   fitting; slice and label colours with the contrast rule.
8. **State** (`lib/wheels.svelte.ts`): saved wheels per server and mine, fetched on open, kept by the events;
   live-spin arrivals (message id → when it arrived) from an event hook and the spinner's response.
9. **`Wheel.svelte`**: SVG slices with thin gaps, labels along the slice, pointer, hub (a Spin button when given
   `onSpin`), a `rotation` prop.
10. **`WheelEditor.svelte`** (shared by the popover and Settings): add (paste `a, b, c`), remove, Shuffle, Clear all,
    with a swatch per option. **`WheelPopover.svelte`** above the composer: Server / Just me (`Segmented`; Just me
    only in DMs and groups), the saved list with "+ New wheel", a name field, the editor, a preview `Wheel`, Spin;
    a quick (one-off) wheel offers **Save as wheel ›** (Server / Just me, then a name). Composer: the wheel button
    (20, as the emoji button it sits beside) and `openWheel(prefill)`; `TextChannel.send` routes `/wheel …`.
11. **`WheelLine.svelte`** in `MessageItem`: a live spin shows the card (the wheel spinning, "alex is spinning Games
    tonight…"), lands, holds the result a moment, then collapses to the line `🎡 alex spun Games tonight → ▮ Valheim`
    with **Spin again**, **Remove winner & spin** (with 3+ options) and, for a quick wheel, **Save as wheel ›**.
12. **Settings**: `WheelSettings.svelte` as Server settings › Wheels (server wheels) and Settings › Wheels (Just me):
    "+ New wheel", each row with its option count, Edit (the shared editor, inline), Rename, Delete (asks first).
13. **Tests**: helpers (parsing, colours' contrast for n = 2..100, winnerAt against server-style angles, rotation
    ends on the angle); the popover (switch, add/paste/remove/shuffle/clear, Save as wheel, Spin invokes); the
    composer (`/wheel a, b, c` spins, `/wheel` opens); the line (lands on the server's winner, collapses, Spin again
    / Remove winner, reduced motion spins short with no tick, late mount is settled); Settings pages; guard tests.
