# Sound sets: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a sound-set picker in Settings → Voice & Audio. It offers 8 whole sets (Classic, Two-step ×3, Minimal ×3,
Goofy), a ▶ preview per set, a 0–100 % sound volume, and an on/off switch per event. It also adds two new events,
`live` and `live_end`, wired into the stream code.

**Architecture:**
- **Assets:** WAVs live at `client/src-tauri/sounds/<set>/<name>.wav`.
  - `scripts/gen_sounds.py` generates Classic, Two-step and Minimal, and owns the normaliser.
  - `scripts/import_goofy.py` builds Goofy from extracted Kenney packs, using the same normaliser.
- **Core:** `sounds.rs` embeds every set with a macro-generated `include_bytes!` table and plays by set + name with a
  volume. The `play_sound` command gains `set` and `volume`.
- **UI:** `voiceui.ts` owns the prefs (`pulse.sounds`), `playSound` and the preview. `SoundSettings.svelte` is the
  section under Voice & Audio. `stream.svelte.ts` plays `live`/`live_end` using pure decisions in
  `stream/viewer.ts`.

**Tech Stack:**
- Python 3 standard library only (no numpy), plus `ffmpeg` (decode only) for Goofy.
- Rust: cpal, the existing `decode_wav`.
- UI: Svelte 5 and vitest + jsdom.

**Spec:** `docs/superpowers/specs/2026-10-26-sound-sets-design.md`. It is binding; executors read it.

- **Public repo:**

    data.
  - Test users are `alex` and `sam`.
- **TDD:** a failing test comes before each implementation. `just check` stays green after every task.
- **Windows:** any Rust change must also pass
  `cargo xwin clippy -p pulse-client --all-targets --target x86_64-pc-windows-msvc -- -D warnings`.
- **Sounds always play in the core**, never through `<audio>`: WebKitGTK aborts.
- **Set ids, exact, in this order:**
  1. `classic`
  2. `twostep-bright`
  3. `twostep-warm`
  4. `twostep-deep`
  5. `minimal-soft`
  6. `minimal-wood`
  7. `minimal-glass`
  8. `goofy`
- **Event names, exact, in this order:**
  1. `join`
  2. `leave`
  3. `mute`
  4. `unmute`
  5. `deafen`
  6. `undeafen`
  7. `message`
  8. `live`
  9. `live_end`
- **Shown names, exact:**
  - `Classic`
  - `Two-step · Bright`, `Two-step · Warm`, `Two-step · Deep`
  - `Minimal · Soft`, `Minimal · Wood`, `Minimal · Glass`
  - `Goofy`
- **Event labels, exact, in event order:**
  1. `Join a call`
  2. `Leave a call`
  3. `Mute`
  4. `Unmute`
  5. `Deafen`
  6. `Undeafen`
  7. `New message`
  8. `Someone goes live`
  9. `A stream ends`
- **Files:** mono PCM16 WAV at 22 050 Hz.
  - Duration: ≥ 0.03 s everywhere. At most 0.35 s for generated sounds, 0.2 s for Minimal and 0.5 s for Goofy.
  - Everything under `client/src-tauri/sounds/` totals ≤ 1 200 000 bytes.
- **Active RMS** = the RMS over the samples from the first to the last sample with |s| ≥ 0.02 × peak.
  - The reference is Classic's active RMS for the same event.
  - Two-step must be within ±1.5 dB of it, and Minimal at −6 dB ±1.5 dB.
  - Goofy must be within ±3 dB of it.
  - Peak ≤ 0.98 for every sound.
- **Classic** is today's 7 files, byte-identical, regenerated by the script.
- **Two-step direction:** these must rise (higher pitch in the last 40 % of the active region than in the first
  40 %): `join`, `unmute`, `undeafen`, `live`. These must fall: `leave`, `mute`, `deafen`, `live_end`.
- **Minimal pairs:** the "on" event is higher than its "off" event: join > leave, unmute > mute, undeafen > deafen,
  live > live_end.
- **Volume:**
  - `play_sound` takes `volume` 0.0–1.0, clamped and multiplied by today's 0.6 gain.
  - A missing volume means 1.0, and 0 plays nothing.
  - The UI keeps `volume_pct` (integer 0–100, default 100).
- **Prefs:**
  - localStorage key `pulse.sounds` holds `{ set, volume_pct, off: SoundName[] }`.
  - The default is `{ set: 'classic', volume_pct: 100, off: [] }`.
- **Preview:**
  - It plays `join, mute, unmute, live, leave`, 450 ms apart, at the current volume, ignoring the event switches.
  - A new preview cancels a running one.
- **Fallback:** an unknown set falls back to `classic` in both the core and the UI.
- **Workspace:**
  - Never bare `git stash`, and no extra worktrees.
  - Downloads go into a fresh directory under the session scratchpad, never into the repo.
  - Python that reads downloaded files runs with `-I`.

### Task 2: Generated sets: Two-step (Bright, Warm, Deep) and Minimal (Soft, Wood, Glass)

**Files:** `scripts/gen_sounds.py`, `client/src-tauri/sounds/{twostep-*,minimal-*}/*.wav`,
`client/src-tauri/src/sounds.rs` (SETS + tests).

**Recipes** (all at 22 050 Hz; every sound is normalised with `normalise()` to the Classic same-event active RMS, and
to −6 dB of it for Minimal):
- **Two-step note:**
  - Each of the two notes is the variant's timbre at a fixed pitch, with a linear attack, a 30 ms release and
    `note` length, with a 25 ms gap between the notes.
  - Variant base `B`, timbre (partial multiples × amplitudes), `note`, attack:
    - **bright:** B = 1047 Hz; partials (1, 1.0), (2, 0.25); note 0.07 s; attack 4 ms.
    - **warm:** B = 659 Hz; partials (1, 1.0), (3, 0.2), (5, 0.08); note 0.085 s; attack 10 ms.
    - **deep:** B = 220 Hz; partials (1, 1.0), (2, 0.5), (3, 0.3); note 0.10 s; attack 6 ms.
  - Pairs as (first, second) multiples of B:
    - join (1, 1.5); leave (1.5, 1).
    - unmute (1, 1.25); mute (1.25, 1). Notes ×0.8 length.
    - undeafen (0.5, 0.6667); deafen (0.6667, 0.5).
    - live (1, 1.6667); live_end (1.6667, 1).
    - message (1.5, 2.0), notes 0.06 s.
- **Minimal note:**
  - One note at `B × m`, with m:
    - join 1.5, leave 1.0
    - unmute 1.3333, mute 1.1225
    - undeafen 1.0 × 0.9 (= 0.9), deafen 0.75
    - live 2.0, live_end 1.6818
    - message 1.8877
  - **soft:** B = 880; pure sine; 0.12 s; raised-cosine (Hann) envelope.
  - **wood:** B = 587; sine + 0.3 × partial at 2.76×; exponential decay τ = 25 ms; 0.12 s; 2 ms attack.
  - **glass:** B = 1319; partials 1 (1.0), 2.76 (0.4), 5.4 (0.15), each decaying (τ 60 ms, 30 ms, 15 ms); 0.18 s;
    2 ms attack.
- Any pitch the recipe makes unworkable (e.g. inaudibly low) may be adjusted by ≤ an octave. The test rules
  (direction, pairs, loudness) still apply. Note it in the report.
