# Calls in DMs and groups, with ringing — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Start and join voice calls in DMs and groups, ring the other members (popover, in-chat band, ringtone, OS
notification), and leave one call line per call that reads "Missed call from sam" for members who never joined.

**Architecture:** The server owns calls and rings. A call opens when a DM/group voice room goes from empty to occupied
(webhook join, or `POST /calls/{channel}`, which is the only thing that rings) and closes 30 s after the room empties.
Open calls and who joined are stored (migration 0022); rings are in memory. The client keeps open calls in the pure
reducer (`state.ts`), rings in one store (`calls.svelte.ts`) that decides popover vs band and gates sound, popover and
notification on DND and conversation mute; the Rust core plays a looping ringtone.

**Tech Stack:** Rust (axum, sqlx/SQLite, ts-rs), Tauri 2 core (cpal), Svelte 5 + vitest, LiveKit.

**Spec:** `docs/superpowers/specs/2026-11-05-dm-calls-design.md` (with `2026-10-01-pulse-design.md` §6–7,
`2026-11-05-status-design.md`, `2026-11-03-volume-mixer-design.md`).

## Review Focus

1. Two members start a call at the same moment: one call, one line, each rings the other at most once (the start
   route and the webhook serialise on one lock). Test: `simultaneous_starts_make_one_call`.
2. A caller who starts a call and never connects: the empty call still ends 30 s later and the ring ends with
   `CallEnded` (or `TimedOut`, whichever first). Test: `a_call_nobody_connects_to_ends_after_the_grace`.
3. Everyone drops and reconnects within 30 s: the same call carries on (no second line). Test:
   `a_reconnect_within_the_grace_keeps_the_call`.
4. A member removed from a group mid-ring: later events never reach them (audience is recomputed from membership on
   every publish). Covered by `ringing_reaches_members_only` (kim joins the group after the ring: gets nothing).
5. The client misses `CallRingEnded` (socket drop): the popover and ringtone still stop at `expires_at`. Test:
   `a_ring_stops_by_itself_at_its_expiry` (client).

### Task 2: Calls on the server (start, ring, decline, timeout, join, end, line, unread, rate limit, Ready)

**Files:** Create `server/migrations/0022_calls.sql`, `server/src/calls/{mod,routes}.rs`, `server/tests/calls.rs`.
Modify `server/src/{lib,config,limits,reads}.rs`, `server/src/voice/{state,routes}.rs`,
`server/src/messages/{routes,system}.rs`, `server/src/gateway/socket.rs`, `server/src/testing/mod.rs`.

**Schema:**
```sql
CREATE TABLE calls (id TEXT PRIMARY KEY, channel_id TEXT NOT NULL REFERENCES channels(id) ON DELETE CASCADE,
  started_by TEXT REFERENCES users(id) ON DELETE SET NULL, started_at TEXT NOT NULL, ended_at TEXT,
  line_id TEXT REFERENCES messages(id) ON DELETE SET NULL) STRICT;
CREATE UNIQUE INDEX calls_one_open ON calls(channel_id) WHERE ended_at IS NULL;
CREATE TABLE call_participants (call_id TEXT NOT NULL REFERENCES calls(id) ON DELETE CASCADE,
  user_id TEXT NOT NULL REFERENCES users(id) ON DELETE CASCADE, joined_at TEXT NOT NULL,
  PRIMARY KEY (call_id, user_id)) STRICT;
```
Line payload (`messages.system_payload`): `{"type":"call","call_id","started_by","ended_at","joined":[…]}`; content
`"<username> started a call"`. `Message.call` is parsed from it (system, not deleted) where messages load.

**Interfaces — Produces (all in `server/src/calls/mod.rs`, state in `VoiceState.calls: CallState`):**
- `pub struct CallTimings { ring: Duration, grace: Duration }` on `Config.calls` (30 s / 30 s; `test_config` 30 s too,
  tests that need speed set ~300 ms).
- `pub async fn start(s: &AppState, me: UserId, ch: &Channel) -> AppResult<StartCallResponse>` — open call → `rang:false`;
  else create call + line, publish `MessageCreated`, `CallStarted`, then `CallRinging` to members − me, arm ring
  timeout and empty grace.
- `pub async fn joined(s, ch: &Channel, user)` — opens a call (no ring) if none; records participant; cancels grace;
  ends `user`'s ring with `Answered`.
- `pub async fn left(s, ch: &Channel)` — room empty now → remember when, arm grace.
- `pub async fn decline(s, me, channel) -> AppResult<()>` — ends my ring with `Declined` (my sessions only).
- `async fn end(s, channel, call_id, ended_at)` — store `ended_at` (= when the room emptied), rewrite the line payload
  (`ended_at`, `joined`), publish `MessageUpdated`, `CallEnded`, and `CallRingEnded{CallEnded}` to every one still ringing.
- `pub async fn for_ready(db, voice, me, visible) -> (Vec<CallInfo>, Vec<CallRing>)`.
- One `tokio::sync::Mutex` serialises start/joined/left/decline/end/timeouts. Private channels only
  (`server_id.is_none()`); server channels never reach these.
- Routes: `POST /calls/{id}` (`channel_for` → 404 for outsiders; 400 for non-DM/group; `limits.call_user`
  `Rate::new(6, 0.05)` → 429), `POST /calls/{id}/decline` → 204.
- Unread SQL (`reads.rs`): `… AND (m.kind = 'normal' AND COALESCE(m.author_id,'') != rs.user_id OR m.kind = 'system'
  AND json_extract(m.system_payload,'$.type') = 'call' AND COALESCE(json_extract(m.system_payload,'$.started_by'),'') != rs.user_id)`.

- [ ] Write `server/tests/calls.rs` (gateway sockets for alex, sam, kim, jo; webhook helpers as in `voice_presence.rs`):
  - `ringing_reaches_members_only` — alex starts in a DM with sam: sam gets `CallRinging` (caller alex, expiry ~30 s),
    alex and an outsider kim get none; in a group alex/sam/jo both sam and jo ring; `rang:true`.
  - `starting_rings_once_and_joining_rings_nobody` — second `POST` while open → `rang:false`, no new ring, same call id.
  - `server_channels_never_ring_or_make_calls` — 400 on a server voice channel; webhook join there → no `CallStarted`.
  - `a_ring_times_out_everywhere` — short timings: sam's two sockets both get `CallRingEnded{TimedOut}`.
  - `decline_ends_my_ring_only_and_tells_nobody` — sam declines: both sam sockets get `Declined`; alex and jo get nothing.
  - `answering_on_one_device_stops_the_other` — sam's webhook join → both sam sockets `Answered`.
  - `the_call_ending_ends_every_ring` — alex leaves, grace passes → jo (still ringing) `CallEnded`; everyone in the

  - `call_presence_never_leaks` — kim (not in the DM) gets no `VoiceJoined`, `CallStarted`, `CallEnded`,
